# angelife 五行首页视觉素材包

用途：给 Codex 进行首页 1:1 版式还原与图片接入。

## 文件放置关系

将本包解压到 Hugo 源码目录：

`/Users/macos/angelife.github.com/hugo-site/`

解压后应出现：

```text
static/images/brand/home-hero-wuxing.png
static/images/sections/metal-judgment.png
static/images/sections/wood-growth.png
static/images/sections/water-yi.png
static/images/sections/fire-ai.png
static/images/sections/earth-right-view.png
docs/design/wuxing-homepage-reference.png
docs/design/wuxing-homepage-wide-reference.png
```

## 视觉目标

宋式书卷气、山水留白、五行色彩、现代信息图表、克制系统感。

顶部只放五行栏目：

```text
金·判断｜木·蝉识｜水·易理｜火·AI｜土·正见
```

首页 Hero：横向画卷，不是居中博客卡片。
五行卡片：一行五张扁平栏目卡。
下方：流程面板 + 各栏目精选 + 最新发声 + 关于本站。
