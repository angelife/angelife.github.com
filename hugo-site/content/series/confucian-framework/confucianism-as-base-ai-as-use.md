# 结论

技术可以提高效率，但不能替人安放价值。本站以儒家为体、AI 为用，是为了让工具服务于正见，而不是让效率放大偏见。

# 背景

AI 时代最容易发生的不是能力不足，而是方向混乱。一个没有价值底层的人，工具越强，越可能把错误系统化。

# 核心判断

格物致知对应资料整理，正名对应概念辨析，修身对应表达边界，中庸对应不过度极端，仁义礼智信对应判断的五个支点。

# 方法论

先格物，再正名；先修身，再发言。AI 可以帮忙整理材料、发现结构、形成初稿，但最后要由人负责判断是否合乎事实、分寸和义理。

# 结语

AI 为用，是器；儒家为体，是方向。器强而无体，容易失控；有体而不用器，难以成事。
