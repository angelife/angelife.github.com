# 结论

判断信息质量，不能只看观点是否顺耳。要先看来源、证据、叙事方式、利益位置和纠错机制。

# 信息源

一个值得长期关注的信息源，至少要能说明事实从哪里来、判断如何形成、出错后如何修正。只输出情绪，不提供证据，只要求站队的信息源，要降低权重。

# 风险信号

常见风险包括：用单个案例概括整体，用敌我话术替代事实，用道德激情掩盖证据不足，用“人民”“正义”“觉醒”等大词绕开具体责任。

# 评分方法

可以从五项打分：事实可查性、论证透明度、情绪煽动度、利益相关性、纠错能力。真正高质量的信息，不怕被追问来源。

# 结语

信息判断的目的不是变得冷漠，而是保护自己的注意力，不把生命交给低质量叙事。
