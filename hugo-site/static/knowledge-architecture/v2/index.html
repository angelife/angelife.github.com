关于安知生

安知生（angelife）是一个长期知识系统的公开入口。以 AI 为工具，以儒家为体，以易理为象，以技术为器，以作品为证。 本站不是普通博客，而是一个把阅读笔记、技术实践、人生复盘逐步整理为系统性作品的站点。 整个站点运行在下面这套 AI 驱动知识系统之上——从输入到处理、知识、编辑再到输出，全链路自动化。

金 · 判断 木 · 蝉识 水 · 易理 火 · AI 土 · 正见 → 浏览栏目

数据流

  • 微信/Telegram/Kindle → Hermes 实时接入
  • MCP 工具调 NotebookLM 查研究资料
  • 提炼洞察 → 结构化存入 Obsidian
  • Obsidian/NotebookLM → Emacs 写作引用
  • Emacs → Hugo 直接编辑发布
  • eshell 在 Emacs 内执行 Hermes CLI
  • Hindsight 记忆自动召回注入上下文

组件

  • Hermes Runtime v2 — 联邦调度
  • MCP (NotebookLM+Gemini+gflow) — 研究+媒体接口
  • OpenBridge — Web 自动化桥接
  • Hindsight — 个人经验向量记忆
  • NotebookLM — 外部资料 RAG
  • Obsidian — 知识图谱 + 笔记
  • Doom Emacs — 编辑工作面 (v2 新增)

出力

  • angelife.github.com 博客（Emacs 编辑）
  • 播客音频 (NotebookLM 生成)
  • 配图/配视频 (Imagen 4 + Veo 3.1)
  • Kindle Dashboard 待决策队列
  • Telegram/微信即时回复
  • LLM Wiki (Obsidian 发布)
  • 系统状态报告 · 项目跟踪
