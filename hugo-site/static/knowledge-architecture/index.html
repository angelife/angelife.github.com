Angelife 知识系统架构

Hermes Runtime · 五行舰队 · NotebookLM(外脑) · Obsidian(内脑) · Hugo

数据流

  • 微信/TG/Kindle → Hermes 实时接入
  • 文章→全文备份到 Obsidian（防删）
  • 导入 NotebookLM 深度分析
  • 分析结果拉回→归档到原文旁
  • 多篇汇总→再喂 NotebookLM 迭代
  • 精炼洞察→写入 LLM Wiki

第二大脑

  • 🔮 NotebookLM 外脑——探索·研究·分析
  • 📒 Obsidian 内脑——沉淀·归档·链接
  • 推→拉→汇总→再推 迭代循环
  • 文章评级 ★1-5 + 适用性评估
  • 交叉链接打通知识点
  • 早晚课评分保证质量

规则核心

  • 先问AI再动手（第一条铁律）
  • 三次规则：两次不过第三次必须问
  • 收敛原则：不用=不存在
  • 强制前检：危险操作先问再动
  • 早晚课：读经→执行→评分→日志
  • 晚课评分：符合+10 / 违反-10
