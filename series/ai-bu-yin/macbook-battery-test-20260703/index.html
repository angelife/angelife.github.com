诊断结论

[COMPUTED, HIGH] 电芯本身健康，问题在燃料计校准：

  1. 电芯通过测试 — Qmax 三节都达标（8,856/8,887/8,835），一致性良好
  2. 燃料计未校准 — MaxCapacity 报 804 mAh（旧电池参数），实际可用约 8,800 mAh
  3. 放电电压正常但加速下降 — 从 12.557V → 11.284V 降 1.27V，负载下表现合理
  4. 负载下不均衡 — 放电时单体压差从 18mV 扩大到 147mV，Cell 3 偏弱
  5. 温度极佳 — 全程 36°C，没有热问题
  6. Service Recommended — 旧电池参数残留 + 负载压降超过 SMC 阈值

需要校准

全放全充循环（放电至关机 → 一次性充满），SMC 应自动更新 MaxCapacity 至接近 Qmax 值。

校准后预期：

  • MaxCapacity：804 → ~8,000+ mAh
  • 续航：~15min → ~3+ 小时
  • Condition：Service Recommended → Normal（可能需 2-3 次循环）
