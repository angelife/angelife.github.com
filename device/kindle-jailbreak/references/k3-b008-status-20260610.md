## Upgrade Necessity Assessment

**Conclusion: Do NOT upgrade to 3.4.1/3.4.3 at this time.**

Reasons:
1. **Jailbreak is already present** — KUAL + KOReader function (the primary goal)
2. **Upgrade destroys jailbreak** — would need full re-jailbreak after upgrade
3. **Re-jailbreak requires MKK** — no MKK files found on device, need to source them
4. **No documented benefit** — current firmware serves KOReader fine
5. **Risk of brick** — if firmware upgrade + jailbreak interaction has compatibility issues

**When upgrade IS warranted:**
- KOReader refuses to run due to "requires newer firmware"
- Current firmware has a known bug affecting reading experience
- User explicitly wants 3.4.x features and accepts re-jailbreak cost
